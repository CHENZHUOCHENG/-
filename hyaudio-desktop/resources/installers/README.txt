====================================================
内置小工具放置说明
====================================================

本文件夹只放【体积小】的自带工具（几 MB 级），
它们会直接打进 setup.exe，用户装完软件就有：

  ai翻唱hyaudio.exe
  hy音频插件清理工具.exe
  新版电音助手安装包.exe

（GitHub 网页上传单文件上限 25MB，这几个都在限内）

====================================================
机架和插件不放这里！
====================================================

机架宿主（Studio One 系列，每个几百 MB）和
插件压缩包（最大 9.8GB）超过了 GitHub 的 100MB
单文件限制，打不进安装包。

它们采用【素材目录】模式：
软件安装后，会自动检测 D:\工具箱素材
（也可在“设置 → 素材目录”里手动选择文件夹），
点“一键安装”时直接从素材目录读取并安装。

分发时：setup.exe + 素材文件夹（U盘/网盘）一起给用户，
用户把素材文件夹放到 D 盘根目录即可被自动识别。

命名不用改——软件会按界面显示名自动模糊匹配素材目录
里的文件（exe 直接调起，zip/rar 自动解压部署插件到
C:\Program Files\Common Files\VST3）。
